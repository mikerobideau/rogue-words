# Holdings data files

Each table is two files:

- **`<table>.csv`**: the one you edit. Readable fields only.
- **`<table>_logic.csv`**: generated by Claude from your text. Don't edit it by hand.

The game reads both when it starts and joins them by `id`. If you change a row's text (or add a row), the game prints a warning in Godot's Output panel naming the row; ask Claude to regenerate the matching `_logic.csv`. Until then the row keeps its old behaviour.

General rules: `id` must be unique and lower_snake_case. Rows whose `id` starts with `#` are ignored. Yes/no columns accept `yes`, `true`, `1`, `y` or `x`.

## cards.csv

| Column | Meaning |
|---|---|
| id | Unique key. Also the art file name in `art/` and `art_silhouette/` |
| name | Display name |
| sector | `Finance`, `Services`, `Industry`, `Tech` or `Consumer` |
| value | Brand earned each time it operates (and when placed) |
| rarity | `common` (3 copies), `uncommon` (2) or `rare` (1) |
| pattern | Dice pattern; blank = needs no die. `odd`, `even`, `low`, `high`, `exact`, `at_least`, `at_most`, `any`, `pair`, `sum_at_least`, `sum_exactly`, `run` |
| pattern_param | Number for `exact`, `at_least`, `at_most`, `sum_at_least`, `sum_exactly` |
| chain_left | yes = also operates when its left neighbour operates |
| copy_left | yes = copies its left neighbour's ability |
| text | The ability, in plain English. This is what the logic is generated from |

Generated in `cards_logic.csv`: card-face short text, tags, effects, triggers, passives and fallback art settings.

## events.csv

| Column | Meaning |
|---|---|
| tier | `mild`, `moderate`, `severe` (or `none`) |
| category | Shown for unrevealed events: `dice`, `economy`, `market`, `business`, `conditional` |
| text | What the event does (the newspaper deck line) |
| weak_text | What it does when weakened by PR Firm. Blank = can't be weakened |

Generated in `events_logic.csv`: effects, weakened effects, goal and penalty.

## offers.csv (Investor Meeting)

`id`, `name`, `text`. Generated: icon and, for edition offers, which edition it grants. A brand-new offer `id` also needs game code to do something; renaming and rewording existing ones is safe.

## editions.csv

`id`, `name`, `text`. Generated: colour. Edition effects are wired in code by `id`.
